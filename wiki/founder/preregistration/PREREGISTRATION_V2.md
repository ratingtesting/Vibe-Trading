## 2. Гипотезы

### H1 — TSMOM-252 (долгосрочный)
- **Механизм:** знак доходности за 252 бара определяет сторону (Moskowitz-Ooi-Pedersen 2012).
  Тренд существует потому, что инвесторы недооценивают информацию (underreaction).
- **Сигнал:** ret252 > 0 → лонг на target-size; ret252 < 0 → flat (спот-крипта, шорт невозможен;
  асимметрия long/short TSMOM — ограничение venue, фиксируем честно).
- **Фальсификатор:** на BTC 12-месячный горизонт — это год лага; knowledge/06 говорит 7–30 дней.
  H1 умрёт, если её EVAL-alpha < 0 или она не переживет ≥5/7 walk-forward окон. Смерть ожидаема
  и полезна: она завершает перенос акционных параметров в крипту.

### H2 — TSMOM-CRYPTO (основная ставка)
- **Механизм:** импульс на крипте живёт 7–30 дней (Caporale-Plastun 2020 doi:10.1007/s11408-020-00357-1;
  Shams 2020). Знак ret за L баров → лонг, иначе flat.
- **Конфигурация (pre-registered, замкнута):** L ∈ {7, 14, 21, 30}; порог = 0 (чистый знак —
  никакой магической константы); опция подтверждения объёмом relVolume20 ≥ 1.0 {вкл, выкл}.
  8 конфигураций, не больше. Отбор: медиана walk-forward альфы по DEV; при равенстве — меньший L
  (правило разрыва предопределено).
- **Фальсификатор:** альфа (return − beta×экспозиция) на EVAL ≤ 0; или t < 3.0; или <5/7 окон.

### H3 — волатильностный фильтр HAR-RV-lite (НЕ directional-стратегия)
- **Механизм:** RV предсказуема (кластеризация; Corsi HAR окна 1-5-22 дня, Zahid 2022).
  Реализованный волатильностный прогноз = w1×RV1 + w5×RV5 + w22×RV22 (веса равные — предопределено,
  НЕ подгоняются).
- **Тест:** MAE прогноза 1-дневной RV против наивного (last RV) и против SMA20(RV) на DEV.
  Успех: HAR MAE < обоих бенчмарков ≥ на 5%.
- **Применение:** при успехе — вход `currentVol` в vol-target sizing (замеченная волатильность
  → предсказанная) и crisis-флаг режим-детектора. Это НЕ сигнал входа; стратегией не заводится.
- **Фальсификатор:** HAR не бьёт наивный прогноз ≥5% → не применяем, точка.

### H4 — режим-гейт (включение стратегии по режиму)
- **Детектор (детерминированный, константы из §1):**
  - crisis: volatility20 ≥ p90 (0.08)
  - trend: adx14 ≥ p50 (27) И trendR2_20 ≥ p50 (0.42)
  - range: adx14 ≤ p10 (15.1) И bbWidth ≤ p50
  - иначе neutral
- **Применение:** новые стратегии торгуют только в разрешённых режимах (H2: trend+neutral;
  без range/crisis). Существующий `regime-filtered.ts` переводится на этот детектор.
- **Фальсификатор:** альфа внутри разрешённых режимов не выше, чем без гейта (гейт не помогает) →
  снять гейт, признать усложнение.

### H5 — churn-фильтр против издержек (утилита, не стратегия)
- **Правило (предопределено):** сигнал не исполняется, если |ожидаемое движение горизонта| <
  **3 × 44 bps = 1.32%**. Ожидаемое движение для TSMOM = |retL| самого сигнала.
- **Фальсификатор:** на DEV фильтр не меняет net-P&L (до/после) или ухудшает — убрать.

## 3. Гейты вердикта (заморожены, понижать нельзя)

| гейт | порог | источник |
|---|---|---|
| minTrades | ≥ 100 сделок | knowledge/05 |
| Nominal Sharpe (EVAL) | ≥ 1.5 | knowledge/05 |
| Deflated Sharpe | ≥ 0.95 при N trials (§5) | Bailey–LdP 2014 |
| t-statistic (H-L-Z) | ≥ **3.0** | Harvey-Liu-Zhu 2016 |
| Walk-forward | ≥ **7 окон**, стабильность ≥ 5/7 по знаку альфы | TEST_PLAN, роль |
| Embargo | 1% между train/val | knowledge/05 |
| Exposure-честность | вердикт по ALPHA (после beta на СОБСТВЕННОЙ экспозиции), не по «vs buy-and-hold» | урок Phase F |
| Издержки | 44 bps round-trip measured | Phase C |

**EDGE = CANDIDATE** только если ВСЕ гейты на EVAL + ≥5/7 окон на DEV. Иначе NO EDGE/INCONCLUSIVE.
Ничто историческое не называется «прибыльным»: финальное доказательство — только forward PAPER.

## 4. Forward PAPER критерии (пре-регистрируются сейчас, исполняются в Фазе 5)

- непрерывные **≥60 календарных дней** и **≥30 исполненных сделок** кандидата;
- фактические (не модельные) издержки ≤ модельным ×1.5;
- просадка ≤ 2 × maxDrawdown-лимит; KILL не сработал ложно >1 раза;
- калибровка Jev: ECE ≤ **0.10**, Brier не хуже случайного 0.25;
- при ECE > 0.10 → Kelly автоматически выключен и результат не считается подтверждением.
