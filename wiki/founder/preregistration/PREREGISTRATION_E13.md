# ПРЕДРЕГИСТРАЦИЯ E13 — базис (перп/спот): событийный вход вместо постоянного кэрри

Дата: 2026-10-16. Фиксируется ДО прогона.

## Гипотеза (механизм, отличный от кэрри)

Базис `b = цена перпа / цена спота − 1` **возвращается к норме**: если перп торгуется заметно дороже спота
(перегрев лонгов), книга «лонг спот + шорт перп» зарабатывает **на схождении базиса** плюс получает funding.
Это НЕ то же, что постоянный кэрри: там мы всегда держим книгу и собираем плату, здесь мы **входим по
событию** (базис перекошен) и выходим, когда он вернулся. Другой триггер → возможна низкая корреляция.

## Данные (уже локальные, ключи не нужны)

`research/data/binance/`: спот 1d (450), перп 1d (100), funding (100), с 2019-09 по 2026-10.

## Дизайн (числа фиксированы здесь)

1. Для каждого символа и дня: базис `b`; `z = (b − среднее за 90 дней) / стандартное отклонение за 90 дней`.
2. Три плеча, на одних данных и одном периоде:
   - **A (эталон)** — кэрри как в C3a: топ-10 по 30-дневному funding, месячный ребаланс.
   - **B (фильтр)** — то же, но держим только символы с `z > 0` (перп перегрет), остальное в деньги.
   - **C (самостоятельное событие)** — вход при `z > +1.5` (или `z < −1.5` → обратная книга), выход при
     `|z| < 0.5` ИЛИ через 10 дней; доход = `−Δбазис + funding`; не более 5 позиций одновременно,
     вес 1/5, **без плеча**.
3. Издержки: 15 bp на ногу, вход и выход (круг по паре — 60 bp).
4. Сплит: DEV < 2024-01-01, EVAL ≥ 2024-01-01 (данные перпов с 2020-01 дают обе половины).

## Гейты вердикта

| Гейт | Порог |
|---|---|
| G1 механизм (C) | DEV t ≥ 3.0 И средняя > 0 |
| G2 удержание | знак на EVAL совпадает с DEV |
| G3 издержки ×2 | средняя C остаётся положительной |
| G4 выборка | ≥ 200 дней и ≥ 20 символов в каждой половине; ≥ 100 завершённых сделок |
| G5 нет подгонки | DSR ≥ 0.95 при trials = 3 |
| **G6 новизна** | корреляция месячных доходностей C с кэрри A **< 0.5** (иначе это тот же край под другим названием) |

**Трактовка:** G1-G6 → **второй край** (годен в ансамбль); только B лучше A (G2/G3) → базис годится как
**фильтр** к кэрри; G1 не взят → механизма нет, закрываем честно.
