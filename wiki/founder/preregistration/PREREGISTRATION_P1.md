# ПРЕДРЕГИСТРАЦИЯ P1 — Polymarket: искажение «фавориты / андердоги»

Дата: 2026-10-16. Фаза: P1 (PLAN_V5 §2). Фиксируется ДО прогона. **Только измерение** — торговля требует
кошелька (решение владельца), здесь его нет.

## Гипотеза (документированное искажение рынков предсказаний)

В рынках предсказаний «андердоги» (низкая цена на исход) систематически **переоценены**, а «фавориты»
(высокая цена) — **недооценены**: люди переплачивают за лотерейные исходы. Проверяем на Polymarket:
сравниваем **цену за 7 дней до резолюции** с **фактическим исходом** и считаем, где отличие велико.

## Данные (бесплатно, без ключей)

- Gamma API: `gamma-api.polymarket.com/markets?closed=true&limit=100&offset=...` — закрытые рынки.
- CLOB: `clob.polymarket.com/prices-history?market=<tokenId>&interval=max&fidelity=1440` — история цен.
- Условия отбора: бинарный рынок (Yes/No), статус `resolved`, объём ≥ $5 000 (отсекаем рынки-пустышки),
  в истории есть точка на ≥1 день до последней.

## Дизайн (числа фиксированы здесь)

1. Целевая цена входа — **последняя известная цена за 7 и более дней до финальной точки истории**
   (первичная мера). Дополнительно считается цена **за 1-3 дня** (вторая мера, отдельный trial).
2. Исход: `outcomePrices` у закрытого рынка (Yes = 1 или 0).
3. **Калибровка по корзинам** цены: 0.00-0.05, 0.05-0.10, 0.10-0.20, …, 0.90-0.95, 0.95-1.00.
   Для каждой: подразумеваемая вероятность (средняя цена) против фактической доли исходов.
4. **Стратегия проверки края:** покупка фаворитов (цена ≥ 0.90) на исход «Yes» и покупка «No» у
   андердогов (цена ≤ 0.10), удержание до резолюции. Издержки: **2% на круг** (у Polymarket нет
   комиссии, но есть спред; берём консервативно), стресс ×2 = 4%.
5. Сплит по дате резолюции: **DEV < 2024-07-01, EVAL ≥ 2024-07-01** (история Polymarket тонкая до 2023,
   фиксированная ранняя дата дала бы DEV без выборки — фиксируем по медиане ДО прогона, а не после).
6. Trials = 2 (два горизонта измерения цены: 7 дней и 1-3 дня), вердикт по 7 дням.

## Гейты (вердикт по таблице, без правок)

| Гейт | Порог |
|---|---|
| G1 искажение существует | \|t\| ≥ 3 у отклонения «факт − подразумеваемое» в крайних корзинах (0-0.10 и 0.90-1.00) |
| G2 стратегия | средняя доходность на сделку > 0 при t ≥ 3 (DEV) |
| G3 EVAL | знак совпадает с DEV |
| G4 издержки ×2 | средняя остаётся положительной |
| G5 выборка | ≥ 300 рынков в каждой половине |
| G6 покрытие | ≥ 5 корзин по ≥20 рынков каждое (иначе калибровка не измерима) |
