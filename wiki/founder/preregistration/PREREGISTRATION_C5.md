# ПРЕДРЕГИСТРАЦИЯ C5 — walk-forward подбор параметров для funding-carry

Дата: 2026-10-16. Фаза: C4-вторая-часть (PLAN_V5 §2). Фиксируется ДО прогона.

## Зачем (один вопрос, один ответ)

Кандидат C3a прошёл гейты при ОДНОМ наборе параметров (топ-10 по 30-дневному funding, месячный ребаланс).
Вопрос: **это край или удачная настройка?** Если край настоящий, то соседние параметры должны работать
почти так же, а лучший по истории конфиг должен удержаться на свежих данных. Если работает ровно один
набор — это подгонка.

## Сетка (объявлена целиком ДО прогона; 48 конфигураций, лимит 64 соблюдён)

| Параметр | Значения |
|---|---|
| Размер книги (топ-N по funding) | 5, 10, 15, 20 |
| Ребаланс | недельный, месячный |
| Окно отбора (средний funding за N дней) | 14, 30, 60 |
| Порог входа (минимальный средний funding за 8ч) | 0 (без порога), 0.005% |

Итого 4 × 2 × 3 × 2 = **48 trials** (все засчитываются в DSR; вердиктный — C3a-конфиг: 10 / месячный / 30 / 0).

## Протокол (walk-forward, без подглядывания)

1. **Подбор ТОЛЬКО на DEV** (< 2023-01-01): для каждой из 48 конфигураций считаем дневную книгу и её
   t-статистику. Выбираем лучшую по t (тай-брейк — по Sharpe).
2. **Подтверждение один раз на EVAL** (≥ 2023-01-01) для: (а) лучшей по DEV конфигурации, (б) вердиктной
   C3a-конфигурации. EVAL больше не трогаем.
3. Печатаем **всю таблицу 48 конфигураций** (DEV t, EVAL t, доходность) — по ней видно, широкий край или
   узкая точка.

## Гейты вердикта

| Гейт | Порог |
|---|---|
| G1 лучшая по DEV конфигурация | положительна на EVAL, t ≥ 2.0 |
| G2 вердиктная C3a-конфигурация | положительна на EVAL (проверка, что подбор не «сломал» исходную) |
| G3 широта края | ≥ 75% из 48 конфигураций положительны на DEV (край — плато, а не игла) |
| G4 издержки ×2 | лучшая конфигурация остаётся положительной на DEV |
| G5 DSR | ≥ 0.95 при trials = 48 |

**Трактовка:** все G1-G5 → «край устойчив, параметры не критичны»; G3 не взят → «край узкий, вероятна
подгонка» — тогда кандидат понижается до «требует пересмотра», и это честный отрицательный результат.
