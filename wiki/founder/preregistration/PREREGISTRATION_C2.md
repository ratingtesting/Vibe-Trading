# ПРЕДРЕГИСТРАЦИЯ C2 — Clenow-моментум (регрессия × R² × ATR-размер) на крипте И акциях

Дата: 2026-10-16. Фаза: C2 (PLAN_V5 §2). Фиксируется ДО прогона.

## Почему это НЕ повтор нашего умершего XS-моментума

Наш XS 12-1 (кросс-секционный, 12 месяцев минус 1) на крипте **мёртв** — измерено дважды. Clenow —
другое семейство:
- сигнал = **сила экспоненциального тренда** (наклон регрессии лог-цены), а не доходность за окно;
- **фильтр качества тренда** R² ≥ 0.80 — берём только ровные тренды, не волатильные рывки;
- **размер позиции обратно волатильности** (ATR), а не равные веса;
- **выход по структуре** (пробой 100-дневной средней), а не по фиксированному сроку.
Источник: Andreas Clenow «Stocks on the Move» / «Trading Evolved», реализация `skyte/momentum`.

## Данные

- Крипта: Binance spot 1d (450 пар, скачано, покрытие ~100%).
- Акции: наш Alpaca-универсум (research/data/universe) — тот же срез, что в V4 (проверяем перенос).
- Вселенная: активы с ≥300 дневных баров; активы с короткой историей исключаются и их число печатается.

## Дизайн (числа фиксированы здесь)

1. Регрессия лог-цены за **90 календарных дней**: наклон b (в день), R².
2. Score = годовая ставка тренда (exp(b·365)−1) × R².
3. Фильтр входа: R² ≥ 0.80 И годовая ставка > 0.
4. Портфель: **топ-10 по score**, равный РИСК на позицию: qty = (риск на сделку = 0.5% капитала) / (ATR(20)·price);
   сумма экспозиций ≤ 100% капитала (плечо ЗАПРЕЩЕНО).
5. Ребаланс: недельный (по понедельникам).
6. Выход: цена < MA(100) ИЛИ R² < 0.5 → позиция закрывается на следующем ребалансе/дне.
7. Издержки: крипта 10 bp + 5 bp проскальзывание; акции 5 bp.
8. Сплит: DEV < 2023-01-01, EVAL ≥ 2023-01-01 (касается один раз).

## Гейты (вердикт по таблице, без правок)

| Гейт | Порог |
|---|---|
| G1 DEV | t ≥ 3.0 И средняя дневная доходность > 0 |
| G2 выборка | n ≥ 500 торговых дней на DEV |
| G3 EVAL | знак совпадает с DEV |
| G4 издержки ×2 | средняя остаётся положительной |
| G5 DSR | ≥ 0.95 при заявленных trials (сетка R² {0.7, 0.8, 0.9} = 3 trials, вердикт по 0.8) |
| G6 заполнение | ≥ 200 ребалансов с непустым портфелем (иначе дефект отбора) |
| **G7 ПЕРЕНОС** | положительная средняя на DEV **и** EVAL **на обоих рынках** (крипта И акции); провал на любом из двух = кандидат НЕ взят |

G7 — главный урок TRANSFER_TEST: кандидат, живущий только на одном рынке, уже дважды оказывался
локальным артефактом и разворачивался вне своего универсума. Поэтому здесь перенос — часть вердикта,
а не дополнительная проверка.
