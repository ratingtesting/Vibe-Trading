# ПРЕДРЕГИСТРАЦИЯ E11 — межбиржевой funding: второй край сопоставимого качества?

Дата: 2026-10-16. Фиксируется ДО прогона. Следствие вывода E10: нужен второй край **сопоставимого
качества**, а не просто независимый.

## Гипотеза

Ставка funding на один и тот же перпетуал **различается между биржами** (Binance / Bybit / OKX), потому
что спрос и предложение на каждой площадке свои. Если выбирать для каждой монеты **самую дорогую площадку**
(по её же прошлому funding), дельта-нейтральная книга «лонг спот + шорт перп» должна собирать больше
платы при том же риске. Это не новое семейство, а **усиление проверенного края** — самый дешёвый способ
поднять качество без ломания механизма.

## Данные (все каналы верифицированы живыми запросами)

- Binance: `fapi.binance.com/fapi/v1/fundingRate` (уже скачано локально, 100 символов).
- Bybit: `api.bybit.com/v5/market/funding/history` (без ключа; проверен в C0 — HTTP 200).
- OKX: `www.okx.com/api/v5/public/funding-rate-history` (без ключа; проверен в C0).
- Окно: с 2021-01 (у Bybit/OKX перпетуалы начались тогда) до сейчас; символы — пересечение площадок.
- **Базис НЕ моделируется** в этом прогоне: измеренный вклад базиса в C3a составил +0.09%/год (шум), а
  издержки и funding — основные слагаемые. Это ограничение заявлено заранее.

## Дизайн (числа фиксированы здесь)

1. Вселенная: символы, у которых есть история funding на Binance И (Bybit ИЛИ OKX), ≥ 200 дней.
2. Три плеча, сравниваются на ОДНОМ периоде и одних символах:
   - **A (база):** всегда Binance, топ-10 по среднему funding за 30 дней, месячный ребаланс.
   - **B (выбор площадки):** для каждого символа берём площадку с максимальным средним funding за 30 дней,
     затем топ-10 монет по этому максимуму.
   - **C (идеальная, как верхняя граница):** площадка выбирается **задним числом** по факту
     (look-ahead) — только чтобы показать, сколько вообще есть в разнице ставок; кандидатом НЕ считается.
3. Метрика: собранный funding в %/год на ногу (и на капитал = ÷2), t по дневным наблюдениям.
4. Издержки переключения площадок: 5 bp на переключение (перевод залога + спред), вычитаются в день смены.
5. Сплит: DEV < 2024-01-01, EVAL ≥ 2024-01-01 (данные Bybit/OKX с 2021 дают обе половины).

## Гейты вердикта

| Гейт | Порог |
|---|---|
| G1 улучшение существует | средний funding плеча B > плеча A (на общем периоде) |
| G2 значимость улучшения | t ≥ 3.0 у парной разницы (B − A) на DEV |
| G3 удержание | знак разницы на EVAL совпадает с DEV |
| G4 устойчивость к переключениям | при издержке 10 bp на переключение средний funding B всё ещё > A |
| G5 выборка | ≥ 20 символов и ≥ 200 дней в каждой половине |

**Трактовка:** все G1-G5 → «межбиржевой выбор площадки даёт улучшение, годное в робот»; G1 не взят →
разницы ставок нет (или она съедается переключениями) — честный отрицательный результат; плечо C выше
плеча B заметно (например, вдвое) → есть смысл искать структурный доступ к разнице (арбитраж), но
торговать «идеальный» выбор нельзя.
