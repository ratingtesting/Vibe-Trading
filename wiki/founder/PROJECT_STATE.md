## 0. ГЛАВНЫЙ ВЫВОД: отбор по статистике не переносится

walk_forward.py разрезает каждый из 34 992 прогонов: train = первые 3 года
(2021-10-20 … 2024-10-19), test = последние 2 года (2024-10-20 … 2026-10-19).
Отбор — **только по train**, test не участвовал. DSR на test посчитан по
полному пулу.

| Показатель | Значение |
|---|---:|
| Корреляция train-Sharpe ↔ test-Sharpe (Пирсон) | **0.0321** |
| То же рангом (Спирмен) | **0.0189** |
| Отобрано на train | 40 |
| Из них прибыльны на test | 22 (55%) |
| Прошли гейт на test (DSR≥0.95, t≥2.5, DD≤20%) | **0** |
| Топ-200 по train, прибыльны на test | **52.0%** |
| Случайная база | **54.7%** |

Преимущество отбора над случайной выборкой — в пределах шума (|z| ≈ 1) на
любом размере; топ-200 по train на test прибыльны **реже** случайных.

**Поэтому нулевой DSR-гейт — это точный ответ, а не «края нет».** Строка,
которая красиво выглядит на 3 годах, не вероятнее случайной устоит на
следующих 2.

Единственная удержавшаяся строка (t ≥ 1.5 на test): `ft_rsi35_65/REQUSDT/raw`
— train 122.3%/год t=2.59 → test 102.6%/год t=2.34, но просадка 39.9%, одна
строка из 40. Её дневные движения совпадают с реальными скачками цены
(день 203: −25.04% против цены −25.00%) — настоящий шорт на мемкоине, а не
артефакт движка.

Худший месяц BTC в окне: **−37%** (июнь 2022). Копилка **концентрирует**
счёт (62–86% в BTC), а не диверсифицирует → просадка растёт
(TSMOM-154: −64.4% → −72.1%).

**Рычаг — порог.** При 10% улучшаются 44% строк против 25% при 30%.
Выигрывают низкокоррелированные сбалансированные `vol10` (DUSKUSDT +3.53 п.п.).

**Правило:** копилку проверять на каждом кандидате отдельно, по его
корреляции с BTC.
