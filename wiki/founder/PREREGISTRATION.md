## 2. Гипотеза: какие семейства берём

Два независимых критерия отбора. Оба опираются на данные, не пересекающиеся по датам с будущей проверкой:

- **Критерий A** — топ-5 по среднему t на СТАРОМ блоке (2020-01-01..2021-10-19).
- **Критерий B** — пережило оба независимых разбиения внутри 5-летнего окна (z > 2 в обоих), то есть прошло проверку на 2021–2026.

Берём **объединение**: семейство в работе, если выдержало хотя бы один из критериев. Критерий B строже, но опирается на большее число наблюдений, поэтому отбрасывать его нельзя.

### 2.1 Правило выбора пары внутри семейства

Фиксируется ЗАРАНЕЕ, чтобы отбор пары не стал новой подгонкой:

1. Берём **все пары**, на которых семейство даёт хотя бы одну сделку (иначе результат невоспроизводим).
2. Внутри семейства пары **не ранжируются по доходности** — ранжирование пар внутри семейства почти целиком шум (проверено: отбор 30 пар даёт на новом блоке средний t +0.156 против +0.442 у отбора 5 пар).
3. Торгуем **все пары семейства равными долями** с vol-риском: одна стратегия, много пар, риск нормируется по волатильности.
4. Если в семействе меньше 10 пар — семейство в пре-регистрацию не берётся (недостаточно наблюдений).

## 4. Протокол проверки (на будущее)

1. Когда появятся данные после 2026-10-19, запустить скан **ровно по этим семействам**, с теми же параметрами и тем же risk-режимом (vol10).
2. Считать на новых данных: доходность в годовых, t, Sharpe на наблюдение, просадку, DSR в узком пуле.
3. Вердикт по каждому семейству: **прошло** / **не прошло** по порогам из раздела 3.
4. Вердикт по гипотезе в целом: семейство считается подтверждённым, если прошло хотя бы одно и **воспроизвело прибыльность на новых данных** (доля прибыльных пар ≥ 60%).

## 5. Что НЕ считается успехом

- Пересчёт с другим порогом или другим окном после получения результата.
- «Семейство почти прошло» (t = 2.2 вместо 2.5).
- Лучшая пара внутри семейства вместо всех пар семейства.
- Перенос правила выбора пары на новый период.
- Утверждение «край есть» на основании того, что семейство вышло в топ на прошлом периоде.

## 6. Ограничения самой пре-регистрации

- Семейства выбраны по данным до 2026-10-19, поэтому в выборе есть подгонка. Признано явно: чистота начинается с первой же проверки на новых данных.
- Оба периода - крипта. На других рынках переносимость может быть другой.
- Данных заканчиваются 2026-10-19: следующего holdout (2027 год) ещё нет, поэтому сейчас пре-регистрация - это обязательство, а не результат.
- Holdout 2020-2021 - медвежий рынок: консервативно для бычьих стратегий, оптимистично для шортовых.
